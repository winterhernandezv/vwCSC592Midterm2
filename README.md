Authenticated Diffie-Hellman Key Exchange
CSC 592 Midterm 2

Description:
This project implements an authenticated Diffie-Hellman key exchange using Python.
It features:
Square-and-multiply modular exponentiation,
Prime generation using PyCryptodome,
Prime factorization,
Generator verification,
Diffie-Hellman key agreement,
Ed25519 digital signatures,
Authenticated message exchange,
Eve attack demonstration

Requirements:
Python 3.13,
Cryptography,
PyCryptodome

Project Files:
modular_math.py,
parameters.py,
participant.py,
authentication.py,
protocol.py,
eve.py,
main.py

Use main.py to perform Authenticated DH Key exchange, and use eve.py for a demonstration of an attack.
